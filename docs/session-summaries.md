# VibraHeal private session summaries

This phase adds printable and downloadable summaries for a current VibraHeal setup or a locally saved session. The summary is an organizational aid for relaxation and mindfulness, not a treatment plan or medical record.

## Included information

A summary can contain:

- the selected tone name and carrier frequency
- listening volume and stereo offset
- session timer
- selected wellness path and the library intention text
- guided-breathing pattern and pace when available
- current saved nature-mixer levels
- an optional personal note typed for this summary
- plain-language sound, breathing, animal-audio, and privacy reminders

For a saved session, tone, timer, volume, offset, wellness path, and linked breathing settings come from that saved session. Nature-mixer levels are global browser preferences rather than part of an individual saved session, so the summary labels them as current configured levels and does not claim they were playing.

## Current-control capture

The **Current controls on this page** option reads the visible listening controls when the summary is opened or refreshed. It captures the selected tone label, carrier range, volume range, stereo-offset range, active timer button, and active wellness path. This capture does not start or stop audio.

## Print and download

- **Print / Save PDF** opens the browser print dialog. PDF availability and wording depend on the browser and operating system.
- **Download HTML summary** creates a self-contained HTML file entirely in the browser. The file can be opened later and printed without an account or cloud service.

All user-entered and locally stored text is escaped before it is placed into the downloaded HTML document.

## Privacy boundary

VibraHeal does not upload summaries or add analytics, accounts, cloud synchronization, or browser-history collection. The summary includes only the values shown in the preview and the optional note typed into the panel.

The feature does not include:

- passwords or payment information
- browser history
- medical records
- audio recordings
- Animal Calm observations
- proof that a setting produces a health outcome

Downloaded files may contain personal session names or notes, so people should store or share them thoughtfully.

## Safety language

Every summary repeats these boundaries:

- VibraHeal is for relaxation and mindfulness, not medical or veterinary advice.
- Begin listening at a low volume and stop if sound feels uncomfortable.
- Headphones are only for a consenting human using stereo offset and must never be placed on an animal.
- Breathing should remain natural; every hold is optional.
- Stop guided breathing if dizziness, strain, shortness of breath, or discomfort occurs.

## Manual review checklist

1. Open **Session summary** and confirm the current controls are represented accurately.
2. Change tone, volume, offset, timer, and wellness path; press **Refresh settings** and confirm the preview changes.
3. Select each saved session and confirm its stored tone, goal, timer, volume, and offset are shown.
4. Confirm linked breathing choices appear for a newly saved session and that an older unlinked session is labeled clearly.
5. Change nature-mixer settings and confirm the preview labels them as configured levels rather than playback history.
6. Enter text containing `<`, `>`, `&`, quotes, and line breaks; download the HTML and confirm the text is displayed rather than executed as markup.
7. Use **Print / Save PDF** and confirm only the summary sheet appears in print preview.
8. Test keyboard navigation, Escape-to-close, larger text, high contrast, reduced motion, forced colors, and a narrow phone viewport.
9. Confirm opening, printing, and downloading a summary never starts or stops tone audio, nature ambience, or guided breathing.
10. Confirm Backup v2, PWA installation, Accessibility, and Animal Calm continue working independently.
